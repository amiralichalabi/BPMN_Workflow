استودیوی BPMN - نسخه ویندوز (فقط برای تست محلی)

پیش‌نیاز: یک SQL Server در دسترس.
  - ساده‌ترین راه: SQL Server Express LocalDB (همراه Visual Studio یا به‌صورت جدا نصب می‌شود). تنظیم پیش‌فرض برنامه همین است.
  - یا SQL Server خودتان: فایل appsettings.json را باز کنید و ConnectionStrings:Default را عوض کنید، یا قبل از اجرا
    متغیر محیطی ConnectionStrings__Default را تنظیم کنید.

1) همه‌ی فایل‌های این پوشه را (نه فقط exe) در یک پوشه‌ی معمولی بریزید، مثلاً C:\BpmnStudio
2) روی BpmnStudio.exe دوبار کلیک کنید. اگر ویندوز هشدار SmartScreen داد: More info > Run anyway (فایل امضا نشده است).
3) یک پنجره‌ی سیاه باز می‌شود و مرورگر به آدرس http://127.0.0.1:8080 می‌رود.
4) در همان پنجره‌ی سیاه، خطی با عنوان INITIAL ADMIN PASSWORD هست:
   نام کاربری: admin   رمز: همان رمز نمایش‌داده‌شده (فقط یک بار چاپ می‌شود)
5) برای خروج، پنجره‌ی سیاه را ببندید.

نکته‌ها
- داده‌ها داخل دیتابیس SQL Server ذخیره می‌شوند (نه کنار برنامه). برای شروع از صفر، دیتابیس BpmnStudio را حذف کنید.
- فقط از همین کامپیوتر در دسترس است (127.0.0.1).
- اگر پورت 8080 اشغال است: متغیر محیطی ASPNETCORE_URLS=http://127.0.0.1:9090 را قبل از اجرا تنظیم کنید.
